# btc_desc 项目文档

本目录是对 `btc_descriptor` 工作区的源码级梳理，面向需要二次开发、调参或复现实验的读者。

## 一句话结论

`btc_desc` 是论文 **BTC（Binary and Triangle Combined Descriptor）** 的 ROS1 官方实现包，用**三角形三边长（全局）** + **平面投影二值图（局部）** 两路特征做 3D 激光点云的**位置识别 / 回环检测**；仓库里唯一可运行的节点 `btc_place_recognition` 在 KITTI 序列上跑"逐帧描述子提取 → 哈希检索投票 → 几何校验 → 回环输出"的完整链路。

## 阅读路径建议

- **只想知道它能干什么** → 读 `01`。
- **想跑通 / 换数据集** → 读 `01` 的"构建与运行" + `04`。
- **想改算法** → 读 `02`（找到阶段）→ `03`（找到结构）→ `05`（避开已知坑）。
- **想造数据 / 换自己的数据集** → 读 `06`，跑 `docs/examples/` 下的生成器与检查脚本；只想快速确认"两份文件该怎么写" → 读 `08`。
- **想把它改成重定位** → 读 `07`，配合 `05` 的 §4.1（未接线 API）与 §6（二次开发建议）。

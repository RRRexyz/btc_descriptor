# 01 项目总览

## 1. 项目定位

`btc_desc`（v1.0.0）是一个 **ROS1 catkin 功能包**，实现了论文 BTC（*Binary and Triangle Combined Descriptor*）所提出的 3D 点云位置识别描述子，随包附带一个 KITTI 上的**回环检测 / 位置识别**示例节点。

- 作者 / 维护者：Chongjian Yuan（袁崇健）、Jiarong Lin（林家荣），`ycj1@hku.hk`
- 论文与视频：`src/README.MD` 中提到论文（arXiv 待发布）、演示视频 <https://youtu.be/zB4Xqi3-J9U>
- 上游仓库：`src/` 是独立 git 仓库，最新一次提交为 `457739d release btc core function && update place recognition example`

核心思想（摘自 `src/README.MD`）：

1. **三角形描述子**：对关键点做 KD-tree 近邻配对，枚举三角形，只用**三条边长**表示。边长与视角、朝向、点云密度弱相关，所以天然具备视角不变性，且存储代价极低（3 个 float）。
2. **二值描述子**：把关键点邻域点投影到参考平面上，按网格 + 深度分层统计占据情况，得到一个 50 bit 左右的 0/1 串，编码局部几何形状。

两路描述子拼接使用：三角形负责**快速候选检索**（边长哈希 + 投票），二值串负责**候选过滤**（相似度打分），最后用平面法向 + 点到面 ICP 做**几何校验**。

## 2. 功能清单

| # | 功能 | 实现位置 | 说明 |
| --- | --- | --- | --- |
| 1 | 体素化 + 体素内平面检测 | `src/src/btc.cpp:758` `init_voxel_map`、`:134` `init_plane` | 每个体素一个 `OctoTree`，PCA 最小特征值小于阈值即判为平面 |
| 2 | 共面平面合并 | `src/src/btc.cpp:814` `get_project_plane`、`:924` `merge_plane` | 法向差 + 点到面距离双阈值，合并后重算中心/协方差/半径 |
| 3 | 参考平面选取 | `src/src/btc.cpp:1031` `binary_extractor` | 按平面点数从大到小，最多取 `proj_plane_num_` 个作投影平面 |
| 4 | 二值描述子提取 | `src/src/btc.cpp:1076` `extract_binary` | 平面投影 + 二维网格 + 深度直方图 → `vector<bool>` |
| 5 | 关键点非极大值抑制 | `src/src/btc.cpp:1373` `non_maxi_suppression` | 按 `summary_` 做半径 NMS，再截断到 `useful_corner_num_` |
| 6 | 三角形描述子生成 | `src/src/btc.cpp:1425` `generate_btc` | 近邻枚举三角形 → 边长排序去重 → 边长量化哈希去重 |
| 7 | 候选检索（投票） | `src/src/btc.cpp:1570` `candidate_selector` | 27 邻域哈希桶 + 边长时间间隔 + 二值相似度 → 逐帧投票 |
| 8 | 候选校验（相对位姿） | `src/src/btc.cpp:1729` `candidate_verify` + `:1823` `triangle_solver` | 三角形顶点 SVD 解位姿，全量匹配投票 |
| 9 | 平面几何打分 | `src/src/btc.cpp:1847` `plane_geometric_verify` | 平面点云变换后法向一致 + 点到面距离内点率 |
| 10 | 描述子数据库写入 | `src/src/btc.cpp:649` `AddBtcDescs` | 以三角形边长整数为键的 `unordered_map` |
| 11 | 平面 ICP 位姿精化 | `src/src/btc.cpp:669` `PlaneGeomrtricIcp` | Ceres 点到面，**已实现但示例未调用**（预留 API） |
| 12 | 可视化与 TP/FP 统计 | `src/example/place_recognition.cpp` | 发布点云/描述子/回环状态；用真值位姿算重叠率判定真阳/假阳 |

## 6. 运行现状

启动文件：`src/launch/place_recognition.launch`

```bash
roslaunch btc_desc place_recognition.launch
```

```xml
<arg name="rviz" default="true"/>
<node pkg="btc_desc" type="btc_place_recognition" name="btc_place_recognition" output="screen"/>
<!-- 注意：下列 param 全部写在 <node> 标签之外（全局命名空间） -->
<param name="cloud_overlap_thr" value="0.5"/>
<param name="read_bin"          value="true"/>
<param name="setting_path"      value="$(find btc_desc)/config/config_outdoor.yaml"/>
<param name="pcds_dir"          value="/mnt/h/kitti/sequences/00/velodyne"/>
<param name="pose_file"         value="/mnt/h/kitti/correct_pose/kitti00.txt"/>
```

> 参数写在 `<node>` 之外意味着它们被放到全局命名空间，节点通过默认 `ros::NodeHandle` 读取同样能取到；但这样做无法用 `roslaunch` 的 `ns` 隔离，属于写法瑕疵，不影响运行。

**当前环境跑不起来的原因**：`/mnt/h/kitti` 不存在。数据与位姿真值都需要自行准备：

- 点云目录：`pcds_dir`，文件名为 `000000.bin` / `000000.pcd` 递增；`.bin` 为每点 4 个 float（x, y, z, intensity）。
- 位姿文件：`pose_file`，**空格分隔 8 列**，格式 `id x y z qx qy qz qw`（详见 [02-数据链路.md](02-数据链路.md) 第 2 步的解析说明）。
- 仓库内 `src/poses/kitti00.txt` 等即为上述格式的真值位姿（kitti00 共 4541 帧），可直接用作 `pose_file`；但点云仍需自备。

其他可调启动参数：

| 参数 | 默认 | 作用 |
| --- | --- | --- |
| `cloud_overlap_thr` | 0.5 | 判定"真回环"的重叠率阈值（仅统计用） |
| `read_bin` | true | true 读 `.bin`，false 读 `.pcd` |
| `setting_path` | config_outdoor.yaml | 算法参数文件 |
| `pcds_dir` / `pose_file` | — | 数据路径 |

## 7. 与本仓库目标的关系

本工作区是在上游 `btc_desc` 基础上做**本地化编译适配**（Ceres 新旧 API 兼容）后的副本，用于继续在此基础上做位置识别相关的研究/开发。算法层面未改动；`src/` 内的 git 状态 = 上游 `457739d` + 一处未提交的 Ceres 兼容补丁。
